# Job Search App

Interactive explorer for 10 roles across LA / SF Bay / Seattle / NYC / Remote, with new grad / 2+ / 5+ / 10+ year filters.

- **Live site**: https://tk3369.github.io/job-search-app/
- **Data**: 825 real listings snapshot 2026-08-28, 817 with full in-app descriptions, source links
- **Stack**: static HTML, no backend, no API key

Daily refresh via Hatch cron `job-explorer-daily-refresh`.
